# GFC v0.2: certificates and adaptive measurement

## Formal model
Graph G=(V,E); each edge e=(u,v,b) constrains x[u] XOR x[v]=b in GF(2). Parallel edges and self-loops are supported.

**Theorem.** There is an assignment satisfying all edges iff every cycle has parity zero. A spanning forest suffices: for every non-tree edge, check the XOR parity on its fundamental cycle. The number of these cycles is |E|-|V|+c.

**Proof sketch.** An assignment implies each closed walk has zero XOR by cancellation. Conversely choose one vertex value per connected component; propagate values along a spanning forest. Each chord condition is met precisely when its fundamental-cycle parity is zero.

## Verifiable outputs
- SAT: an explicit bit assignment; checker verifies every edge.
- UNSAT: a set of distinct edge indices forming an even-degree subgraph with odd XOR parity. No bit assignment can satisfy it, since XORing its constraints yields 0=1.
- Readout: a seed-dependent fundamental-cycle basis and the parity signature. Any nonzero signature is equivalent to UNSAT; individual signatures depend on the basis.

## Adaptive readout
Randomized spanning forests are sampled; the configuration minimizing total cycle lengths is selected. This cost is a *proxy* for edge traversals, not a verified improvement in physical energy or wall-clock runtime. Certifying an instance is exact; optimizing the measurement layout is heuristic. No learning across problem instances is claimed yet.

## Experiments
```bash
python -m unittest -v
python -m gfc
```
The first command runs 500 randomized small graphs against brute force in addition to edge-case tests. The second currently only imports the module.

## Next research stages
1. Held-out, cross-instance training instead of optimizing one graph.
2. A fair baseline and accounting for optimization overhead.
3. Noisy sensor model, false-positive/false-negative rates, and a separate proof checker.
4. Nonabelian relation holonomy using a precise gauge-covariant formulation.

## Limitations
This is proof-of-concept graph computation built on known mathematics. It does not establish an advantage over linear-time graph traversal for parity constraints, or solve arbitrary SAT problems.
