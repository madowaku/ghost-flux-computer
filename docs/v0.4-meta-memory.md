# GFC v0.4: Ghost Meta-Memory

## Research question

Can **topology-conditioned policy selection** use structural information in a
new graph to choose a useful readout basis, outperforming a **single globally
trained readout policy** on unseen graph mixtures?

Unlike GFC v0.3, which persists just one policy, v0.4 stores an interpretable
decision stump: *if topology feature <= threshold use policy A, else B*.
The training objective uses measured readout lengths, not unsatisfiability
labels. Thus the model chooses arrangements without peeking at cycle flux.

## Hypothesis and limits

H1: If the data distribution contains graph regimes with different best
readout policies, a topology-conditioned rule can reduce the held-out
**sum of fundamental-cycle lengths** versus a best global policy learned
on the same training set.

H0: No systematic benefit, or benefit vanishes on held-out sets,
stronger baselines, or after the learning and feature-computation overhead.

This is a standard small-scale algorithm-selection approach with novel
application framing. It does not discover new theorems, hardware,
or faster algorithms. Exact XOR satisfiability is already O(n+m) by standard
graph traversal; a lower edge-visit readout proxy cannot establish a speedup
over that baseline.

## Measurement and training

Features are computed from graph topology only, invariant to vertex
relabeling and bit-flips of edge constraints:

* density (unique non-loop edges)
* max degree relative to number of vertices
* transitivity (3 * triangle count / connected triples)
* degree heterogeneity (mean squared degree / squared mean degree)

The six policies are inherited from `ghost_memory.py`:
random, hub, anti_hub, triangle, hub_triangle, and low_triangle.

For each training instance `G_k` and policy `p`:

```
L(G_k, p) = (sum fundamental-cycle lengths) / max(1, m_k * max(1, n_k))
```

Train the best global policy, then exhaustively test all thresholds between
adjacent observed feature values. Each branch selects the lowest aggregate
training loss policy with at least `min_leaf` instances. A conditional
split is accepted only if it beats the global loss by more than the
`split_penalty` (default 0.0002). This penalizes trivial overfitting,
but is not an optimal guarantee or calibrated statistical test.

A learned memory is serializable JSON with schema version, global and
conditional policies, threshold, feature and training statistics.

## Reproducible held-out study

```bash
python -m unittest discover -v
python benchmark_meta.py --train-per-family 60 --test-per-family 80 --memory-out meta_memory.json > meta_results.json
```

Train on **60 modular + 60 dense** synthetic graphs.
Never evaluate on those graphs. Evaluate on separately seeded:

* 80 held-out modular graphs
* 80 held-out dense graphs
* pooled 160 unseen modular + dense graphs
* 80 shifted grid graphs
* 80 shifted hub graphs

Both topology families are synthetic and may make the feature-separability
problem artificially easy. No family label is given to the trained model.
The generator uses randomly relabeled vertices. For each evaluation graph
compare **paired seeds** for the learned meta rule, the training-best global
policy, fixed hub, and random.

Additionally report a post-hoc oracle which picks the best of six policies
after seeing their realized costs. It is merely a bound on the potential
within the current policy set, not a deployable runtime baseline.

## Falsifiability and overhead

Success requires improved held-out measurement proxy compared with the best
single *training-selected* policy and the fixed hub baseline, not just random.

Always report graph-level wins, ties, losses, and the shift-family performance.
Both global ERM and meta-ERM share the same six-policy training probes.
Record their total visits as a reproducible proxy, but do not treat all training
probe costs as *incremental* overhead relative to global ERM. The extra cost
of computing topology features, searching thresholds, sorting, memory access,
and circuit rewiring is not included. Therefore a fair end-to-end amortization
break-even is **not yet measurable**. A rigorous end-to-end advantage has
**not** been demonstrated.

The proof layer remains `gfc.certify` / `verify_conflict`; a policy selects
only a fundamental-cycle basis. For any basis:

```
all cycle-flux bits == 0  <=>  XOR graph is satisfiable
```

A change of basis can change the signature coordinates, but not whether
an obstruction exists.

## First held-out experimental results (GitHub Actions, 2026-10-10)

[Verified initial experiment](https://github.com/madowaku/ghost-flux-computer/actions/runs/38019475311).

- The global policy chosen by training was `hub`.
- The meta rule chose `hub_triangle` at density <= 0.19210526315789472,
  and `hub` otherwise.
- Training contained 120 graphs: 60 modular and 60 dense.
- Observations were made on disjoint synthetic test graphs.

| Unseen graph family | Fixed hub | Meta rule | Difference |
|---|---:|---:|---:|
| Modular (80) | 3,300 | 3,257 | 1.30% fewer edge visits |
| Dense (80) | 17,827 | 17,827 | equal |
| Mixed pooled (160) | 20,968 | 20,910 | 0.28% fewer edge visits |
| Grid shift (80) | 5,963 | 5,976 | 0.22% worse |
| Hub shift (80) | 5,862 | 5,862 | equal |

This is a **small, distribution-specific** proof-of-concept improvement in
readout length. It is not a measured compute advantage. The training six-policy
probe budget was 120,574 cycle-edge visits (22,800 for the random-policy probes
alone). The candidate evaluation itself and topology-feature overhead remain
unaccounted for. The best-fixed-hub comparisons are paired per test set.

The earliest CI run used a mismatched seed for the optional post-hoc oracle.
That diagnostic has been corrected to use the same per-instance evaluation
seed, and its value is not considered evidence of a speed advantage.
A pre-registered replication on more graph seeds, alternative families, and
stronger classical spanning-tree baselines is essential.

## Going beyond meta-heuristics

Future work: structural online learning, a richer policy space,
streaming update rules, fast feature extraction, noise-robust witness
certificates, and comparisons against a fixed BFS spanning tree and classical
graph algorithms. Validate on pre-registered external benchmarks before
claiming a new computational principle.
