# Ghost Flux Computer (GFC)

An exploratory research project studying computation via constraint inconsistency certificates, graph-cycle flux, and adaptive measurement architectures.

## Scientific scope

For binary edge constraints `x[u] XOR x[v] = b[e]`, a graph is satisfiable exactly when the XOR of `b` along every cycle is zero. This is established mathematics, not a new theorem. GFC explores its use as a computational architecture.

The planned v0.2 prototype separates **exact certification** from **heuristic observation-layout optimization**. It makes no claims of quantum speedup, hardware power savings, or general NP-hard speedups.

See the forthcoming `research/gfc-v0.2` branch and pull request for executable code and tests.
